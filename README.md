# MyGrocer Ecommerce Website
An ASP.NET Core MVC project for an online grocery store. This project demonstrates Singleton patten, Factory pattern and observer pattern.

### Prerequisites

- Visual Studio 2022
- .NET SDK
- SQL Server
- SQL Server Management Studio (Optional)

### Installation

1. Clone the repository

```bash
git clone https://github.com/qaiou/mygrocer.git
```

2. Open the solution in Visual Studio.

3. Configure your SQL Server connection string in `appsettings.json`.

4. Apply Entity Framework migrations.

```powershell
Update-Database
```

5. Run the application.
